# Reference material

Page images of the open-access paper used as the main technical reference of this project:

> José Ignacio Rojas-Sola, Gloria del Río-Cidoncha, Arturo Fernández-de la Puente Sarriá, Verónica Galiano-Delgado.
> *Blaise Pascal's Mechanical Calculator: Geometric Modelling and Virtual Reconstruction.* Machines 2021, 9(7), 136.
> https://doi.org/10.3390/machines9070136 — licensed **CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).

The images are unmodified renders of pages of the published PDF (100 dpi, JPEG), included here only so a session without PDF tooling can look at the figures. Original full PDF: https://pdfs.semanticscholar.org/7d8d/b42e370fd04e019c430a568c5d0ec02a3ef1.pdf

Credit for this paper must appear at the end of the project README and as a small "Credits" link on the site.
